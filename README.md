# SamueleMoscatelli/tap

Homebrew formulae for [Pulse](https://github.com/SamueleMoscatelli/pulse), the static analyzer
and Quality Gate for AI assets.

```sh
brew install SamueleMoscatelli/tap/pulse
```

`Formula/pulse.rb` is generated by each Pulse release (the `pulse.rb` release asset); don't edit
it by hand.
